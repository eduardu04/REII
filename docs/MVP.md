# MVP — entrega inicial (30%)

Requisitos técnicos da cadeira (Moodle):
- inovador e tecnológico, com **3 funcionalidades principais** (login, registo e perfil não contam);
- integrar sistemas de terceiros ou hardware, ou ser colaborativo;
- não depender de uma base de dados pré-existente; dados nos ecrãs dinâmicos.

Funcionalidades propostas (a fechar pelo Manel com base nos mockups):
1. **Caracterização do imóvel** — localização, área, tipologia, estado; dados colaborativos anónimos (renda/preço real).
2. **Simulação vender vs arrendar** — motor financeiro: cash flow, VAL, TIR; taxa de juro via API BPstat.
3. **Explicação por IA** — interpreta os indicadores calculados, com fontes e pressupostos.
